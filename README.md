# Pipeline de Extração de Texto utilizando OCR

Projeto desenvolvido para reconhecimento automático de texto em imagens utilizando técnicas de processamento de imagens e OCR.

## Tecnologias

- Python
- OpenCV
- EasyOCR
- Tesseract

## Funcionalidades

- Pré-processamento de imagens
- Conversão para escala de cinza
- Binarização
- Redução de ruído
- Extração de texto
- Comparação entre EasyOCR e Tesseract

## Estrutura

```
images/
results/
src/
```

## Como executar

```bash
pip install -r requirements.txt

python main.py
```

## Objetivo

Este projeto foi desenvolvido para estudar técnicas de Visão Computacional e Reconhecimento Óptico de Caracteres (OCR), comparando diferentes abordagens para melhorar a taxa de reconhecimento.
